# Game Forensic Engine & MCP Server

[![License: MIT](https://img.shields.io/badge/License-MIT-green.svg)](./LICENSE)

Анализ жалоб Steam (EN/RU), выявление гринда (GTI), сопоставление геймплейных циклов (CoreLoop) и нативный **MCP-сервер** (Model Context Protocol) для ИИ-агентов (ZCode, OpenCode, Claude Desktop, Cursor).

```bash
pip install -e '.[dev]'
python -m game_forensic.cli 1091500
python -m game_forensic.cli recommend 1091500
```

## MCP Сервер (Model Context Protocol)

Движок работает как stdio JSON-RPC MCP-сервер, предоставляя инструменты для LLM:
- **`steam_analyze_game`**: глубокий форензик-анализ (GTI, анти-ачивки, 5-осевой профиль, вердикт).
- **`steam_match_backlog`**: сравнение двух игр по 5 осям CoreLoop (векторное сходство геймплея).
- **`steam_batch_filter`**: параллельный отсев дрочилен из бэклога по заданному порогу гринда (`max_grind`).
- **`steam_recommend`**: подбор похожих игр по CoreLoop и анти-гринд фильтру.
- **`steam_search_games`**: поиск игр в Steam Store по ключевым словам.
- **`steam_blacklist_add`**: добавление игры в персональный `blacklist.json`.
- **`steam_blacklist_remove`**: снятие игры с блэклиста, включая встроенные записи.
- **`steam_profile_set`**: сохранение 5-осевого профиля игры в `profiles.json`.

### Запуск MCP
```bash
python -m game_forensic.mcp_server
# или через entrypoint
game-forensic-mcp
```

### Подключение в OpenCode / Claude Desktop / ZCode
```json
{
  "mcpServers": {
    "steam-forensic": {
      "command": "python",
      "args": ["-m", "game_forensic.mcp_server"],
      "cwd": "E:\\workspace\\code\\game-forensic-engine"
    }
  }
}
```

## Рекомендации

- SteamPeek через существующий HTML-адаптер pipeline; Steam Store `More Like This`
  дополняет список, если кандидатов мало. Это публичные страницы, не выдуманный
  официальный REST API. Блокировки, пустые страницы и изменения разметки отражаются
  в статусах источников; подмена случайными играми не выполняется.
- Blacklist применяется до загрузки отзывов. Начальный список включает Lost Ark
  (1599340), по ранее подтверждённым P2W/таймгейтам. CLI-файл дополняет список;
  библиотечный `MatcherConfig(blacklist={})` позволяет заменить его полностью.
  Снять запись можно через `steam_blacklist_remove` или значение `null` в файле.
- Не более `--max-candidates 20` игр проверяются пакетами с `--concurrency 3`.
  Решение о безопасности принимается **только** общей функцией `policy.safety_gate`,
  поэтому CLI, `Matcher` и все MCP-инструменты отвечают одинаково.
  RED_FLAG_REJECT и INSUFFICIENT_DATA исключаются всегда; CAUTION исключается при
  наличии категорий time_gating / pay_to_skip. CAUTION только по гринду остаётся
  с предупреждением. Ошибки, таймауты и неподтверждённые базовые игры исключаются.
  Если в `steam_batch_filter` задан `max_completion_hours`, но длительность оценить
  нельзя, игра отклоняется с кодом `LENGTH_UNKNOWN`. Без лимита неизвестная
  длительность не влияет на решение.
- `steam_match_backlog` возвращает `store_verified` для обеих игр. Если Steam Store
  не подтвердил название эталона или кандидата, вердикт — `UNVERIFIED_GAME`, а не
  рекомендация. Неподтверждённый эталон также останавливает `Matcher.recommend`.
- Кандидаты, прошедшие проверку, но не вошедшие в топ-5, попадают в `excluded`
  с причиной и своими метриками. Ни один кандидат из `raw_candidates` не теряется
  молча — он либо в `ranked`, либо в `excluded`.
- `steam_batch_filter` обрабатывает не более 8 игр за вызов; сколько записей
  отброшено по лимиту и сколько AppID не удалось определить, видно в `warnings`
  и полях `skipped_over_limit` / `unresolved_count`.
- Лексический анализ (GTI и оси) поддерживает только EN/RU. Другие языки
  скачиваются, но в отчёт не влияют — об этом всегда есть предупреждение.
- Оси: combat_pace, build_depth, tactile_feedback, punishment_severity,
  narrative_weight. Каждая ось в [0, 1], от низкой интенсивности к высокой.
  Профили имеют приоритет над `Game.loop` и текстовыми EN/RU признаками.
  Неизвестные оси не заполняются нейтральными значениями.
- `Similarity = sum(w * (1 - abs(reference - candidate)) * min(confidence)) / sum(all w)`.
  Равные веса по умолчанию; покрытие — доля веса известных общих осей.
  Минимальное покрытие 40%, иначе кандидат исключается. Сортировка: сходство
  по убыванию, GTI по возрастанию, затем AppID; выводится не более пяти игр.
  В JSON также есть нескорректированное vector_similarity и common_dimensions.
- GTI — не вероятность оттока и не сертификат безопасности. Тактильность по
  текстам — приближение, не измерение задержки ввода. Для качественного сравнения
  используйте вручную проверенные профили. Ноль обнаруженных жалоб не доказывает
  отсутствия P2W/таймгейтов.

`profiles.json` (пример формата, числа не являются готовой оценкой игры):

```json
{
  "1091500": {
    "combat_pace": 0.7,
    "build_depth": 0.8,
    "tactile_feedback": 0.6,
    "punishment_severity": 0.3,
    "narrative_weight": 0.9
  }
}
```

Добавляйте профили кандидатов в тот же JSON-объект. Можно задавать только известные
оси; недостающие оси будут извлечены из доступных описаний и отзывов.

`blacklist.json`:

```json
{"12345": "Вручную подтверждённый обман ожиданий: описание причины", "1599340": null}
```

`null` (или пустая строка) снимает запись, включая встроенную. Некорректные
значения — не строка и не `null`, неизвестные оси, значения вне [0, 1] — не
ломают инструмент: они пропускаются, а в ответе появляется предупреждение.
CLI выводит такие предупреждения в `stderr`, не смешивая их с JSON-отчётом.
Чтение повреждённого JSON даёт предупреждение, но mutating MCP-инструмент не
перезаписывает повреждённый или не являющийся объектом файл: операция завершается
ошибкой. Запись выполняется атомарной заменой; параллельные изменения внутри
процесса сериализуются.

Коды завершения: 0 — рекомендации получены, 2 — нет проверенных рекомендаций,
1 — ошибка конфигурации/ввода-вывода, 130 — прерывание. Причины исключения и
предупреждения доступны как в таблице, так и в JSON. `--review-pages`, `--languages`,
`--min-reviews`, `--cache-dir`, `--proxy`, `--timeout` работают для обеих команд.

```bash
python -m pytest -q
```
